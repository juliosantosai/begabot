# Módulo: media-switcher-service

Propósito:

Procesar y normalizar mensajes multimedia (notas de voz, ubicaciones) fuera del flujo principal.

Archivos clave:

- `server.js`, `controllers/mediaSwitcherController.js`, `Dockerfile`, `test/`

Tests incluidos:

- Unitario: `test/mediaSwitcher.unit.test.js`
- Integración: `test/mediaSwitcher.integration.test.js`

Cómo ejecutar tests:

```bash
cd media-switcher-service
npm install
npm test
```
