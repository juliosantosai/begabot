# Módulo: servicio-agente-ia

Propósito:

Integra modelos de IA para soportar capacidades conversacionales y decisiones automatizadas.

Archivos clave:

- `ai-gemini-agent.js`, `server.js`, `package.json`, `Dockerfile`

Cómo ejecutar en desarrollo:

```bash
cd servicio-agente-ia
npm install
npm start
```

Pruebas:

- Hay tests en `servicio-agente-ia/tests/` (si existen). Ejecutar `npm test` desde el directorio.

Notas:

- Asegurarse de tener las credenciales/keys necesarias en variables de entorno antes de iniciar.
