# Contributing to BegaBot 3.0

Gracias por querer contribuir. Sigue estas pautas para mantener la calidad del proyecto.

1. Bifurca (fork) y crea un branch descriptivo desde `main`.
2. Añade tests para cambios relevantes.
3. Actualiza la documentación (`docs/`) si introduces nuevas APIs o cambios de comportamiento.
4. Asegúrate de que los servicios relevantes pasen sus tests localmente.
5. Abre un Pull Request, describe los cambios y vincula issues relacionados.

Commit messages:
- Usa el prefijo tipo(scope): descripción. Ej: `feat(core): add generic query endpoint`
